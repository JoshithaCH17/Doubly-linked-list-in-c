# Doubly Linked List in C

A menu-driven C program implementing a
doubly linked list using dynamic memory.

## Features
- Insert at beginning
- Insert at end
- Delete from beginning
- Delete from end
- Forward traversal
- Backward traversal

## Concepts Used
- Structures
- Pointers
- Dynamic memory allocation
- malloc() and free()
- Doubly linked lists

## How to Run

Compile:
gcc doubly_linked_list.c -o doubly_linked_list

Run on Windows:
.\doubly_linked_list.exe

## Language
C
